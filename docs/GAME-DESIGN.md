# AI 领地 · 游戏设计文档（治愈田园版）

> **文档性质**：手写维护的"设计与决策"文档——记录玩法设计的意图、数值与理由。
> 字段级细节看自动生成的 `DATA-MODEL.md` / `PROTOCOL.md`；架构看 `ARCHITECTURE.md`；本文件的变更走人工评审。
>
> 基调决议：**治愈田园**——压力温和、矛盾以和解收尾、永远不会有村民真正死于饥寒。
> 规划：迭代 1「生存循环」→ 迭代 2「活人感」→ 迭代 3「进度与表达」，每期结束均可玩。

---

## 1. 设计支柱与基调

### 三根支柱

| 支柱 | 一句话 | 判据：一个改动要不要做 |
|---|---|---|
| **活人感** | 村民是"人"不是"工人单位" | 这个改动让村民更像人吗？ |
| **田园治愈** | 压力温和，麻烦都有出路 | 最坏情况会让玩家挫败/心疼吗？会 → 削 |
| **小领地成长** | 玩家能感到领地在"长大" | 一周后回来看，能一眼说出"变强了"吗？ |

### 基调细则（ heals 规则）

- **没有死亡**：精力归零 ≠ 死亡 = 状态"精疲力尽"——工作速度减半、只散步和抱怨，吃饭后恢复
- **事件是"麻烦"不是"灾难"**：损失永远可恢复（≤当天产能），不搞毁灭性打击
- **矛盾以和解收尾**：争吵事件必有和解路径（时间或领主调停），不产永久仇恨
- **AI 上限**：凡是"人味"的内容（对话/叙事/反应）优先交给 LLM；凡是数值结算用确定性规则——两者以"LLM 出叙事与决策，规则出结算"为界

### 明确不做（防止范围发散）

战斗/战争系统 · 科技树 · 多领地 · 村民死亡 · 硬性失败/倒计时失败

## 2. 玩家体验目标（理想的一小时）

```
0-10min   下几道指令，看村民认领、干活、互相搭讪 —— "他们是活的"
10-25min  第一次事件（暴雨/商人），看到村民的反应与叙事 —— "居然还会这样"
25-45min  秋天结束前意识到要囤粮，组织采集潮，入冬 —— "我有在经营"
45-60min   冬夜看村民围炉对话、清晨收到晨报 —— "我想再过一年"
```

软目标（里程碑，无失败）：撑过第一个冬天 · 人口达 10 · 建成磨坊 · 第一场婚礼 · 全员挚友。

## 3. 循环设计

| 循环 | 周期 | 内容 |
|---|---|---|
| 核心循环 | 分钟级 | 观察 → 下令 → 村民认领执行 → 事件/反馈 → 调整 |
| 季节循环 | 天级（1 季 = 7 游戏天） | 春耕 → 夏育 → 秋收（囤！）→ 冬歇 |
| 元循环 | 周级 | 人口增长 → 建筑解锁 → 关系戏剧 → 里程碑 |

治愈田园的关键：**压力的节奏是"可预期的季节 + 低频随机事件"**，玩家永远有时间准备，紧张感来自"来不及"而非"不知道"。

## 4. 系统设计

### 4.1 时间与季节

- 现有刻度不变：10 tick/s，1 天 = 6 真实分钟（1x）
- **一年 = 4 季 × 7 天 = 28 游戏天**（1x 约 2.8 小时，4x 约 42 分钟）
- 季度从春季开始， 世界创建日 = 春 1 日

| 季节 | 世界修正 | 视觉 |
|---|---|---|
| 春 | 浆果产量 ×1.25；农田劳作效率 ×1.25 | 嫩绿色调、小花 |
| 夏 | 无修正；事件权重偏向"丰收前兆" | 浓绿、偶发蝉鸣音效（远期） |
| 秋 | 浆果产量 ×1.5；**系统在秋 1 日发提醒事件** | 金黄色调 |
| 冬 | 浆果**全部枯竭且不再生**；农田劳作不可用；精力消耗 ×1.25；移动速度 ×0.9 | 雪色覆盖、灰蓝天光 |

冬季生存账（数值推导）：每人每天消耗约 2.6 食物（2 餐 + 冬季加成），7 天 ≈ 人口×18；**舒适线 = 人口×20，底线 = 人口×12**。秋季全力采集（每天可入 15~20 食物）完全可达标——紧张但治愈。

### 4.2 食物与精力

| 食物 | 获得方式 | 食用效果 | 定位 |
|---|---|---|---|
| 浆果（生食） | 采集浆果丛 | 精力 +45（现状不变） | 主食，全季（冬除外） |
| 小麦 | 农田劳作产出（替代现在"直接 +2 食物"的设计） | 不可直接食用 | 原料 |
| 面粉 | 磨坊 workflow：小麦×3 → 面粉×2 | 不可直接食用 | 中间品 |
| 面包 | 烘焙 workflow：面粉×1 + 浆果×2 → 面包×1 | 精力 +70 | 深秋/冬季主力 |

- 吃饭规则不变（精力 <30 → 去仓库吃 1 份）；优先吃面包，没有吃浆果
- **新增"低效"状态**：精力 ≤15 时工作单位耗时 ×1.5、移动 ×0.8——温和惩罚，不阻止行为

### 4.3 建筑功能化

| 建筑 | 现状 | 新功能 | 迭代 |
|---|---|---|---|
| 民居 | 睡觉处 | **人口上限 +2/座**（初始领主堡容纳 6） | 迭代 1 |
| 粮仓 | 观赏 | **库存上限 +150/座**（基础 300） | 迭代 1 |
| 农田 | 产食物 | 改产小麦（冬停） | 迭代 1 |
| **磨坊** | — | 解锁磨面/烘焙 workflow | 迭代 1 |
| **酒馆** | — | 社交聚集点：空闲村民傍晚向酒馆聚集，闲聊概率 ×2；节日场地 | 迭代 2 |
| 铁匠铺 | — | 解锁工具（效率 +10%） | 迭代 3 |

### 4.4 人口与迁入

- 初始 6 人；**无出生/死亡**；**暂不增长**——旧的"流浪者投奔"事件已移除（随机空降一个旅人太突兀，且整套审批链路只为它服务）
- 人口增长未来规划：**繁衍机制**（结婚生子），另行设计

### 4.5 事件系统（骨架 + 首批事件）

**骨架**：事件定义为 JSON（id/季节权重/前置条件/效果/叙事模板）；世界线程每游戏小时掷骰一次，命中即触发；触发时 narrate 生成叙事入日志，效果走工作单/库存结算。**治愈基调权重：好事 : 麻烦 = 7 : 3**，且同类麻烦 7 天内不重复。

**首批事件表**（已落地：商人、暴雨、野狗；"流浪者投奔"已移除，2026-09）：

| id | 类型 | 触发 | 效果 | 叙事/村民反应 |
|---|---|---|---|---|
| merchant | 好 | 夏/秋，每月≤1 次 | 开启 1 次交易机会（用石×6 换面粉×4，或跳过） | 商人入场→与村民寒暄（对话管道） |
| harvest_festival | 好 | 秋 7 日，食物 ≥ 人口×10 | 全员聚集领主堡，精力回满，随机两人好感 +2 | 丰收祭叙事；对话高发 |
| rain_damage | 麻烦 | 春/夏/秋 | 随机 1 座建筑 progress -30（最低 40） | 自动生成维修工作单；涉事村民抱怨一句 |
| dog_steal | 麻烦 | 任意（冬季权重↑） | 库存 food -6 | 发现者气泡抱怨；记忆"野狗偷粮" |
| berry_bloom | 好 | 夏/秋 | 当日浆果产量 ×2 | 采集者气泡欢呼 |
| lost_in_fog | 麻烦(轻) | 冬/春夜 | 1 名村民次日晨归，带回"雾中见闻"（LLM 怪谈，治愈风） | 归来时自动对话分享 |
| old_friend | 好 | 每季≤1 次 | 领主堡外来客与村民长谈 | 全员记忆 +1，随机两人好感 +1 |

### 4.6 关系与社交戏剧

关系值现状：每次对话双方 +1。新增阈值戏剧（检查时机 = 每次对话结束）：

| 阈值 | 关系 | 戏剧 |
|---|---|---|
| ≥5 | 好友 | 双方获得记忆"我们成了好朋友"；协作工作（同工地）速度 +10% |
| ≥12 | 挚友 | 互赠礼物事件（小事件：一方送浆果，另一方精力 +10） |
| ≥10 且双方面包管够 | 恋人线 | 丰收祭共舞 → 求婚对话（LLM 写）→ 婚礼大事件（全员参加、誓词 LLM、日志庆祝） |
| <0 | 龃龉 | 争吵事件：两人各自抱怨气泡；和解路径 = 领主调停指令 或 3 天后自动和解（治愈基调：必有出口） |

### 4.7 性格数值化（Traits）

worldgen 生成村民时，LLM 额外输出 1~2 个**特质标签**（词表约束）：

| 标签 | 数值效果 | 表现效果 |
|---|---|---|
| 勤劳 | 工作单位耗时 ×0.9 | 气泡更积极 |
| 懒散 | 工作单位耗时 ×1.1 | 散步概率 + |
| 健谈 | 主动闲聊概率 ×1.5，社交冷却 -50% | 更常发起对话 |
| 腼腆 | 被选为对话对象概率 ×0.5 | 更少出现在对话里 |
| 爱吃 | 精力消耗 ×1.1，吃饭效果 +10 | 常聊吃的 |
| 胆大 / 谨慎 | 事件角色分配偏好（查雾/迎狼去胆大） | 事件叙事提及 |
| 乐观 / 悲观 | 气泡语气与台词风格（prompt 层） | 台词风格差异 |

性格自由文本（personality）继续进 prompt 不变——标签是**数值层**，自由文本是**语言层**，两者叠加。

### 4.8 点击村民对话（玩家 ↔ 村民）

- 交互：点击村民 → 详情面板"交谈"按钮 → 聊天面板（输入框 + 台词流）
- 村民上下文：人设 + 最近记忆 + 当前心情（精力/事件）+ 对领主的态度（最近被赏/罚）
- 约束（治愈+防刷）：同一村民每天深聊 ≤2 次，超了会回"先干活啦领主大人"；对话不影响其正在执行的 workflow（他一边干活一边回头答你）
- 实现：新端点 `POST /api/villager/{id}/chat` → 路由到该村民 goroutine 的对话处理（复用 dialogue 管道与限流），输出 = 台词面板 + 世界气泡双发

### 4.9 村民自主决策层级（brain）——LLM 在行为层的落点

村民的"下一步"由三层决策构成，LLM 是主路径、规则是兜底：

| 层 | 谁 | 何时 | 做什么 |
|---|---|---|---|
| 1. 领主规划器 | 世界线程 planner | 领主下令时 | 自然语言 → 工作单（世界级拆分） |
| 2. **村民规划器（brain）** | 村民 goroutine | 空闲 + 思考冷却到点 | LLM 从意图词表选下一步：输入 = 人设/性格/精力/私有记忆×5/**村庄账本新闻×5**/工作履历×5/库存与时间；输出 = {intent, params, reason} |
| 3. 心跳维护 | 村民 goroutine（规则） | 每 1s | 夜晚/饥饿/精力（不经 LLM） |

- **意图词表（v1）**：gather_wood / gather_food / gather_stone / farm_tend / socialize / idle_wander——只含"自发力行为"，建造类仍由领主工作单驱动（需要工地参数）
- **公共记忆层（WorldLedger）**：领主指令 / 世界事件（建筑落成）/ 对话八卦三类入账；brain 读最近 5 条新闻 = **传闻传播**（别人的对话会影响你的决策）；对话八卦的摘要带当事人标记
- **工作履历**：最近 20 条（认领/完成/失败）进 prompt——经历影响选择
- **回退**：LLM 超时(30s)/解析失败/非法意图 → 规则掷骰（原行为），管道永不断；决策理由（reason）写入记忆与日志，可观测
- **频率与成本**：每人每冷却期（40~130 游戏刻）一次小请求——BYOK 便宜模型即可，设置页 token 仪表可见

已落地：~~反思改为回顾昨天（统计昨日记忆 ≥5 才触发）+ 洞察注入 brain prompt（U3 闭环）~~——2026-09 已移除（每游戏日固定一次 LLM 消耗，但洞察只影响官员 prompt，玩家与平民侧几乎无感知，判定为"无游戏推动"）。后续：特质标签加权 → ai_choice 事件反应扩面。

### 4.10 领主日志（晨报）

每天清晨（EvDay 时）由 narrate 角色生成 3 行"昨日速览"（关键事件/库存变化/一句村民语录）→ 日志置顶 + 面板展示。解决"挂机一晚回来不知道发生了什么"。

### 4.11 赏罚

点击村民 → 表扬/训斥 → 目标村民心情（精力 ±10）与记忆（"领主表扬了我"/"被训斥了，有点委屈"）→ 短期工作效率 ±10%。每天对同一人限 1 次。

## 5. 迭代计划与验收标准

### 迭代 1「生存循环」—— 打通"压力→决策→后果"

内容：季节系统 · 食物三级链（小麦/面粉/面包 + 磨坊）· 事件骨架 + 商人/流浪者/暴雨/野狗 · 民居人口 · 粮仓容量 · 低效状态

验收：
- [ ] 从春玩到冬（4x 约 42 分钟），冬季前不囤粮会明确感到食物紧张，囤了则平稳过冬
- [ ] 磨坊→面包链路可被指令驱动并正确消耗/产出
- [ ] 4 个事件在正确条件下触发，效果与叙事入日志
- [ ] 民居建成后人口上限生效，流浪者可迁入
- [ ] 全程 mock 可回归测试（事件调度/季节结算有单测）

### 迭代 2「活人感」—— AI 卖点兑现

内容：点击村民对话 · 关系阈值戏剧（好友/挚友/恋人/婚礼/争吵和解）· 酒馆 · 性格数值化

验收：
- [ ] 可与任意村民连续对话，其内容引用最近记忆与事件
- [ ] 一局内自然出现好友 ≥2 对，婚礼事件完整演出
- [ ] 争吵出现且可通过调停指令和解
- [ ] 酒馆建成傍晚出现聚集行为

### 迭代 3「进度与表达」—— 长线动力

内容：晨报 · 赏罚 · 里程碑庆祝 · 交易深化 · 个人愿望 · 铁匠铺工具

## 6. 数值附录

- 食物账（6 人开局）：日耗 ≈ 12 浆果（2 餐/人）；初始浆果丛可持续供给 ≈ 15-17/日 → 温饱线以上，冬季是第一个真正的缺口
- 库存上限：基础 300 + 粮仓 150/座
- 季节事件权重：好事 0.7 / 麻烦 0.3；同麻烦事件冷却 7 天
- 对话频率：村民自发闲聊冷却 40~130 游戏刻（现状）；玩家点击对话 2 次/人/天
